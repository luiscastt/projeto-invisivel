# Contrato de integração do MVP

Atualização: `GET /territories/{code}/context` retorna os cadastros oficiais de saúde, escolas, obras, convênios, gestão SINISA e agregados da ouvidoria estadual. `GET /territories/{code}/facilities` retorna GeoJSON somente dos pontos compatíveis com os limites municipais disponíveis, com contadores de qualidade. Esses registros não são inseridos em `/issues`. Coleções indicam `available`, `total`, `fetched_at`, `stale` quando pertinente e notas de cobertura. SINISA preserva o período 2023 da edição 2024; escolas são somente a rede estadual do ES e ouvidoria estadual não é a API operacional federal.

API prefix `/api/v1`, JSON, cookies same-origin, erros `{detail: string}`. Lista territorial e catálogo retornam arrays. Datas ISO UTC. Códigos IBGE são strings. GET público sem autenticação; escritas exigem sessão. Categorias `infrastructure`, `sanitation`, `mobility`, `education`, `health`, `environment`. Estados de acompanhamento `reported`, `corroborated`, `in_progress`, `declared_resolved`, `verified_resolved`, `contested`.

## Base inicial oficial

GET /api/v1/issues aceita origin=official ou community. Os itens incluem origin, official_records_count e location_precision. Latitude, longitude e first_reported_at podem ser null quando a fonte não fornece informação válida. O detalhe inclui official_records_total e até 20 metadados de registros oficiais, com origem verificável.

O resumo municipal separa official_records, official_issues, community_issues, reports e not_assessed; coverage.official_problem_sources informa a cobertura inicial. source_removed é arquivamento da fonte, excluído dos totais ativos, sem indicar resolução. Encerrada no registro da fonte não implica verified_resolved. Dossiês temáticos oficiais não entram em fusão de ocorrências físicas e, sem localização, ficam fora da alocação por custo unitário físico no simulador (excluded_official_dossiers).
